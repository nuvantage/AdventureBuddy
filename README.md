# Adventure Buddy: Get Active Together.

Adventure Buddy is a map-based journal of every walk, hike, and outing you share with your dog — see your shared adventures build up over time.

**Status: early development**

## Details

- **Xcode project / bundle name:** `AdventureBuddy`
- **Home screen name:** Adventure Buddy
- **App Store display name:** Adventure Buddy: Get Active Together.
- **Minimum iOS:** 17.0
- **UI:** SwiftUI
- **Architecture:** MVVM (`Models/`, `Views/`, `ViewModels/`, `Services/`, `Resources/`)

The App Store name is 37 characters, which is over Apple’s 30-character limit. Shorten it in App Store Connect before submission if needed (for example, “Adventure Buddy: Get Active”).

## Opening the project

Open `AdventureBuddy.xcodeproj` in Xcode 15.4 or later on a Mac, choose an iOS 17+ simulator, and run.
